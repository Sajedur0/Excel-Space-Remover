# Excel Space Cleaner

একটি সহজে ব্যবহারযোগ্য টুল যা Excel ফাইল থেকে লিডিং ও ট্রেইলিং স্পেস সরিয়ে দেয়।

## Run করার নির্দেশনা

**১ম উপায় (সহজ):** `run.bat` ডাবল ক্লিক করুন

**২ম উপায় (কমান্ড লাইন):**
```bash
streamlit run main.py
```

ব্রাউজারে `http://localhost:8501` এ ওপেন হবে।
